## How to use a prompt

1. Open a new chat in an AI assistant your organisation has approved, and attach your file.
2. Copy the prompt and replace the parts in [SQUARE BRACKETS].
3. Read the result. Ask the assistant to explain anything unclear, or to change the output.
4. When the result is right, ask: "Turn this into a reusable tool I can run on a new file each month."

AI finds red flags faster. The investigator still proves the case: every flag is a lead until source documents confirm it.
