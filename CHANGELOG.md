# Changelog

## 0.1.0 — November 2026

First release, published for Fraud Week 2026.

- Browser toolkit: load CSV or Excel files, automatic column matching, adjustable settings, results with Excel, CSV and PDF export. Runs fully offline in the browser.
- Four tests: duplicate payments, vendor–employee match, journal entry testing, Benford's Law.
- Fake sample data with planted red flags for every test.
- Twelve prompt guides for fraud investigators.
- Automated checks for every test.
